# Hell King Scythe (Fabric 1.21.1)

## Jar kaise banayein
1. Java 21 install karo (https://adoptium.net).
2. Windows: `build.bat` double-click. Mac/Linux: `./build.sh`.
3. Jar milega: `build/libs/hellking-scythe-1.0.0.jar` (sources wali jar mat lena).
   (Pehli baar 5-10 min lagte hain, internet chahiye.)

Ya GitHub par upload karo -> Actions tab -> build -> Artifacts se jar download.

## Install
Minecraft 1.21.1 + Fabric Loader 0.16+ + Fabric API (1.21.1) -> jar ko `mods` folder mein daalo.

## Use
- Recipe: `NNS / _B_ / _B_` (N = Netherite Ingot, S = Nether Star, B = Blaze Rod). Creative > Combat tab mein bhi hai.
- Scythe haath mein pakdo, **V** dabao -> Hell King transformation (2 sec charge).
- **Space double-tap** = superman flight, **G** (hold) = flame beam, **R** = fireball, **V** = wapas normal.
- Keys Options > Controls > "Hell King Scythe" mein badal sakte ho.

## Heaven King (v6)
- Heaven Trident: recipe `SSN / _I_ / _I_` (S = Diamond, N = Nether Star, I = Packed Ice), also in Creative > Combat.
- Trident haath mein pakdo + **V** = Heaven King (wings, halo, crown, cape). Scythe pakdo + V = Hell King.
- **Space double-tap** = flight, **G** (hold) = neon water laser (blocks ice ban jaate hain), **R** = water ball (bada crater, paani se bhara, upar ice ki layer).
- Hell King ab fire/lava/explosion/fall damage se immune hai aur screen par aag nahi dikhti.

## Wind Assassin (v7)
- Void Katana: recipe `__P / _N_ / S__` (P = Phantom Membrane, N = Netherite Ingot, S = Stick), also in Creative > Combat.
- Katana haath mein + **V** = Wind Assassin (kaala skin, safed chamakti aankhein, kamar par 2 katanas).
- **Left click (M1)** = kaala slice VFX + chhota lunge, combo har baar alag cut.
- **G** = horizontal samurai slash: sab blocks/ped kat jaate hain, mob ka bhaari damage + poison.
- **R** = dono katanas fenko. Solid block mein gadte hain, dirt/sand/gravel/grass/leaves kaatke aage jaate hain, mob/player mein ghus jaate hain. Paas jaoge to poison dekar wapas aa jaate hain.
- **B** = katanas nikalo / wapas rakho.
- Hell King ke liye naya skin (hell_skin.png) lagta hai.
